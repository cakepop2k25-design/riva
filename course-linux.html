COURSE 02 · BEGINNER

Linux Fundamentals

Learn the Linux command line and the basic concepts needed to work comfortably in a Linux environment.

Lesson 1 — What is Linux?

Linux is an open-source operating-system kernel used by many distributions, including Ubuntu, Debian, Fedora, and Kali Linux. Different distributions package tools and software for different needs.

Lesson 2 — Navigating folders

Common commands include pwd to print the current directory, ls to list files, and cd to change directories.

pwd
ls
cd Documents

Lesson 3 — Files and directories

mkdir practice creates a directory named practice. touch notes.txt creates an empty file on many Linux systems. Practice in a folder you own and check paths before changing or deleting files.

Lesson 4 — Users and permissions

Linux permissions help control who can read, write, or execute files. Avoid running commands with administrator privileges unless you understand what they do.

Lesson 5 — Updates and software

Use your distribution's official package manager and documentation. Read prompts before approving changes, and keep backups of important files.

Knowledge check

1. Which command shows your current directory?

2. Which command lists files?

3. When should you use administrator privileges?
